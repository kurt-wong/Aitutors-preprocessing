## 2. Scope Document 五要素(你起草,我核验)

### 2.1 Scope(只验证一个问题)

> **Admission Boundary 是否能够阻止没有满足 Evidence Authority 要求的 Evidence 进入 Admission。**

验证的是 **enforcement**,不是:Evidence Authority 最终架构设计 / Resolver 是否应消费 options_region / HTML 如何处理 / Producer Contract 如何冻结。

### 2.2 Inputs(必须写明 authority chain)

```
SourceVersion → Producer Evidence Region → Experimental Adapter output → Evidence state → Gate decision → Admission request
```

**每层必须标注:是 producer fact / 实验 adapter 构造物 / V3 当前正式对象**。用户原话:"不要让实验 adapter 偷偷成为'第二套 V3'"。

### 2.3 Metrics(至少含)

| Metric | 含义 |
|---|---|
| valid evidence accepted | 合法 Evidence 能否正常通过 |
| invalid evidence rejected | 非法 Evidence 是否被阻止 |
| unvalidated evidence rejected | 未经 Validation Authority 的 Evidence 是否被阻止 |
| cross-run evidence rejected | 跨 run 污染是否被阻止 |
| mutated evidence rejected | Evidence 被篡改后是否被阻止 |
| **bypass path count** | **是否存在绕过 Evidence Authority 的 Admission 路径(核心)** |

bypass path count 为核的原因(用户原话):"你之前最大的疑点就是 EvidencePromotion / ValidationEvent 虽然存在,但 Admission 是否真正依赖它?P3.2 就应该直接攻击这个边界。"

### 2.4 Negative Acceptance(至少 N1–N8;核心 = N7/N8)

```
N1 EvidenceClaim exists, but no ValidationEvent
N2 ValidationEvent exists, but invalid result
N3 Evidence from another run
N4 Evidence references wrong SourceVersion
N5 Evidence validity expired / invalidated
N6 evidence payload mutated after validation
N7 direct Admission attempt bypassing promotion   ← 核心攻击项
N8 gate_decision = approve but Evidence Authority invalid ← 核心攻击项
```

N7/N8 直接验证既有疑点(EB-003/BUG-V3-048 线):**Admission 到底由 Gate decision 单独控制,还是由 Evidence Authority 真正控制?**

**负面验收的哲学(用户原话)**:这个实验最重要的不是证明"好的 Evidence 能进去",而是证明**"坏的 Evidence 进不去"**。

### 2.5 Non-goals(必须原样写死进文档)

```
This experiment does NOT decide:
- whether options_region becomes a production Resolver input
- whether HTML parsing belongs to Producer or Resolver
- whether Resolver rules should change
- whether Producer Contract should change
- whether Evidence Authority architecture should be frozen
- whether EB-005 should be implemented
```

实验中发现问题,唯一合法出口:

```
OBSERVED → EVIDENCE → REPORT
```

不是 `OBSERVED → 修改架构`。
